# SerialTool 项目说明

这是一个 Windows 下的串口调试工具项目。

## 目录说明

- `src/`：源码目录
- `exe/`：打包输出目录
- `build/`：PyInstaller 临时构建目录

## 代码在哪

- 主程序：`src/serial_tool.py`
- 图标资源：`src/icon.ico`
- 打包脚本：`src/build.bat`

## exe 在哪

- 生成后的程序：`exe/SerialTool.exe`

## 怎么打包

直接双击 `src/build.bat`。

脚本会自动：

1. 检查 `pyinstaller`
2. 关闭正在运行的 `SerialTool.exe`
3. 用 PyInstaller 打包
4. 输出到 `exe/SerialTool.exe`

## 备注

- 程序窗口图标和任务栏图标都使用 `src/icon.ico`
- 如果你改了代码，重新跑一次 `src/build.bat` 就行

## 测试脚本

`src/test_serial_tool.py` 是本项目的**功能自测脚本**（开发用），用 PyQt5 离屏模式（offscreen）运行，不弹界面、不依赖真实串口，把主程序的功能逐项验证：

- 发送链路：HEX/文本转换、HEX 偶数位校验、CRC16/ADD/XOR 校验、第 N 字节至末尾-K 字节范围计算
- 加回车换行：主发送、多字符串点击发送、循环发送是否都正确追加 `\r\n`
- 多字符串面板：注释添加/修改/清空、单击发送 vs 双击只编辑（含慢速双击不误发）、循环遇空条跳过、含逗号注释的 ini 导入导出往返
- 配置持久化：保存参数 → 重启恢复是否一致
- 界面行为：扩展/隐藏窗口尺寸不变、面板显隐、网格间距、ANSI 过滤、刷新串口

测试中的弹窗（消息框/输入框/文件对话框）都被替换为模拟返回值，可全自动跑完。

运行方式（需 PyQt5、pyserial）：

```
QT_QPA_PLATFORM=offscreen python test_serial_tool.py
```

跑完打印每条 PASS/FAIL 与“结果: N 通过, M 失败”，有失败时退出码非 0。每次改完 `src/serial_tool.py` 跑一遍即可回归。

注意：该脚本只在 `src/` 目录开发用，不会打进 exe（打包只包含 `serial_tool.py`），不要也可以直接删除。
